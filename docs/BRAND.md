# NYALES

Nama produk disepakati pada 17 Oktober 2026. Identitas visual mengikuti design system 1.1: Poppins, navy, krem, teal dan peach.

Mark: huruf N dengan satu garis membulat dan dua terminal. Terminal mewakili awal/hasil aktivitas sales; tidak menyatakan fitur routing. Square radius 22/64; clearspace minimum 8/64. Ukuran ikon minimum 24 px; favicon 16 px memakai varian mono bila titik aksen tidak terbaca.

Varian navy menjadi default sidebar/favicon; light untuk latar gelap; monochrome untuk cetak satu warna. Wordmark teks “nyales” menggunakan Poppins Medium, tracking -0,04em. Logo bukan indikator status; warna endpoint tidak mempunyai arti performa.

File master SVG berada di public/brand. SVG merupakan aset vektor yang dapat diedit; tidak memakai foto atau stok logo pihak lain. Pemeriksaan merek dagang belum dilakukan.
